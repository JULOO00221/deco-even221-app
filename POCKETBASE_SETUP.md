# Deco Even221 — PocketBase setup

This app talks to your own PocketBase server. Configure the URL on the **Login** page (click "Configure PocketBase server").

## Required collections

### `users` (auth)
PocketBase's built-in auth collection — already exists.

### `clients` (base)
| Field   | Type   | Required |
|---------|--------|----------|
| name    | text   | yes      |
| email   | email  | no       |
| phone   | text   | no       |
| address | text   | no       |

### `Prestations` (base)
| Field        | Type   | Required |
|--------------|--------|----------|
| name         | text   | yes      |
| description  | text   | no       |
| unit_price   | number | yes      |
| unit         | text   | no       |

### `Devis` (base)
| Field      | Type     | Notes                                        |
|------------|----------|----------------------------------------------|
| number     | text     | unique, auto-generated by the app (DEV-YYYY-####) |
| client     | relation | → `clients` (single)                          |
| event_date | date     |                                               |
| Salle      | text     |                                               |
| items      | json     | array of `{name, quantity, unit_price, service_id?}` |
| subtotal   | number   |                                               |
| tax        | number   |                                               |
| total      | number   |                                               |
| status     | select   | options: Brouillon, Envoyé, Validé, cancelled       |
| signature  | text     | data URL (PNG)                                |
| Validé_at  | date     |                                               |
| notes      | text     |                                               |

## API rules
For each collection, set the API rules so that authenticated users can list/view/create/update/delete:

```
@request.auth.id != ""
```

## CORS
Make sure your PocketBase instance allows the domain where this app is hosted (PocketBase has CORS open by default).
